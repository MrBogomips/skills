# port-to-agents

`port-to-agents` adapts a Claude Code project to work with Codex. It makes `AGENTS.md` the single instruction file for both tools (with `CLAUDE.md` as a symlink to it) and converts the project's skills, agents, MCP servers, hooks, and permissions for Codex with rulesync.

## Why

Running both tools on the same project usually leaves you with two instruction files that drift apart, or a generated copy that goes stale after every edit. On its own, rulesync only copies files; run by hand, it overwrites `AGENTS.md` with a copy of `CLAUDE.md` and invents a Codex approval policy.

This skill maintains one shared `AGENTS.md`, proposes every change to an instruction file as a diff for your approval, and records in `AGENTS.md` how and when to regenerate the Codex files.

## Installation

```bash
npx skills add MrBogomips/skills --skill port-to-agents
```

This installs the same skill from the `skills` plugin, under the name `port-to-agents` instead of `skills:port-to-agents`.

## Usage

Ask explicitly to port or sync the project to Codex, or invoke the skill directly (it does not run automatically):

```text
/skills:port-to-agents
```

When the project has configuration to convert, the skill asks how to manage the generated Codex files:

- **static**: committed and regenerated manually after a source file changes.
- **dynamic**: gitignored and regenerated by a setup step on every checkout.

At the end, it reports what changed and what will be missing in Codex.

## Inputs and outputs

- **Reads:** the instruction files (`AGENTS.md`, `CLAUDE.md`, `.claude/CLAUDE.md`, `.claude/rules/`), `.claude/skills/`, `.claude/agents/`, `.claude/settings.json`, and `.mcp.json`.
- **Produces:** `AGENTS.md` as the shared instruction file with a "Codex interop" section, `CLAUDE.md` as a symlink to it, Claude Code-specific lines in `.claude/CLAUDE.md`, and the generated `.agents/skills/` and `.codex/` directories.

## Requirements

You need an agent harness with a shell, git, and a POSIX `sh`. When `.claude/` or `.mcp.json` contains configuration to convert, you also need Node (`npx`) with network access to run the latest version of rulesync.

## Limitations

- This skill ports only from Claude Code to Codex. To create a plain `AGENTS.md` without Codex tooling, use `init-agents-md`.
- Not everything carries over: `.claude/rules/` and `.claude/commands/` are not ported, and converted agents lose their `model`, `effort`, `tools`, and `skills`. See [references/rulesync-gaps.md](references/rulesync-gaps.md) for the full list.
- On Windows, `core.symlinks` must be enabled before cloning; otherwise, `CLAUDE.md` is checked out as a plain text file.
