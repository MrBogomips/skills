# port-to-agents

`port-to-agents` makes Codex work in a Claude Code project. `AGENTS.md` becomes the one instruction file both tools read, with `CLAUDE.md` as a symlink to it, and the project's skills, agents, MCP servers, hooks and permissions are converted for Codex with rulesync.

## Why

Two tools on one project usually mean two instruction files that drift, or a generated copy that is stale after every edit. rulesync alone only copies files: run by hand, it overwrites `AGENTS.md` with a copy of `CLAUDE.md` and invents a Codex approval policy.

This skill keeps one shared `AGENTS.md`, proposes every change to an instruction file as a diff you approve, and records in `AGENTS.md` how and when to regenerate the Codex files.

## Installation

```bash
npx skills add MrBogomips/skills --skill port-to-agents
```

It is the same skill as in the `skills` plugin, installed under the name `port-to-agents` instead of `skills:port-to-agents`.

## Usage

Ask explicitly to port or sync the project to Codex; the skill does not run otherwise.

```text
/skills:port-to-agents
```

When there is something to convert, it asks how the generated Codex files are kept: **static**, committed and regenerated by hand after a source changes, or **dynamic**, gitignored and regenerated by a setup step on every checkout. It ends with a report of what changed and what Codex will lack.

## Inputs and outputs

- **Reads** the instruction files (`AGENTS.md`, `CLAUDE.md`, `.claude/CLAUDE.md`, `.claude/rules/`), `.claude/skills/`, `.claude/agents/`, `.claude/settings.json` and `.mcp.json`.
- **Leaves** `AGENTS.md` as the shared file with a "Codex interop" section, `CLAUDE.md` as a symlink to it, Claude Code's own lines in `.claude/CLAUDE.md`, and the generated `.agents/skills/` and `.codex/`.

## Requirements

An agent harness with a shell, git and a POSIX `sh`. Node (`npx`) with network access runs rulesync, always at its latest version, and is needed only when `.claude/` or `.mcp.json` holds something to convert.

## Limitations

- It ports from Claude Code to Codex only. To create a plain `AGENTS.md` with no Codex tooling, use `init-agents-md`.
- Not everything carries over: `.claude/rules/` and `.claude/commands/` are not ported, and a converted agent loses its `model`, `effort`, `tools` and `skills`. The full list is in [references/rulesync-gaps.md](references/rulesync-gaps.md).
- On Windows, `core.symlinks` must be on before cloning, or `CLAUDE.md` arrives as a text file.
