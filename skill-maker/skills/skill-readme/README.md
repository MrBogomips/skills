# skill-readme

Checks and drafts the public `README.md` for a plugin and every skill it distributes. You get review
notes listing each issue with its file, section, and evidence, plus a short README for each
component in draft mode.

## Why

A handwritten README drifts from the code, while an unchecked draft from a model invents commands or
repeats the entire `SKILL.md`. This skill keeps each README concise and accurate: a script checks
structure and size, and a separate reviewer verifies each statement against the component's files.
It also preserves existing content.

## Use cases

### Find what is wrong with an existing README

**Context:** Your plugin has gained an agent and a setting since its README was written.

**Action:** Run `/skill-maker:skill-readme check <plugin folder>`.

**Result:** Review notes in the reply, listing each finding by section and line.

### Restructure a README without losing its content

**Context:** A skill README has its own sections, including one generated by a tool.

**Action:** Run `/skill-maker:skill-readme draft <skill folder> <output folder>`.

**Result:** A draft with the contract sections first and existing sections kept after them, plus a
`review-notes.md` file with the remaining questions for you.

## Usage

```text
/skill-maker:skill-readme check|draft <plugin or skill folder> [output folder]
```

`check` is read-only. `draft` writes to the output folder and never overwrites an existing README;
the skill applies a draft only when you ask. If you omit the folder, the skill uses the plugin in
the working directory.

See [references/contract.md](references/contract.md) for the required README sections.

## Requirements

The `skill-maker` plugin and Python 3.9 or later as `python3`.

## Limitations

- Works on one plugin at a time.
- Verifies statements against files without running the component.
